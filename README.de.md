## Was ist der Piraten-Token?

Der Name, den die Community für den **Piraten-Token (Pirate Shop Access Token)** benutzt — die Event-Währung der Treasure-Hunters-Mini-Season. Du verdienst ihn, indem du während der Matches hochstufige vergrabene Piraten-Truhen (Buried Pirate Chests) plünderst, und gibst ihn im Piraten-Item-Shop aus.

## Der schnellste Weg dorthin (TL;DR)

1. Droppe in die Küstenzonen, in denen vergrabene Piraten-Truhen spawnen.
2. Grabe High-Tier-Truhen aus — sie droppen die meisten Token pro Match.
3. Spiele während der Schatzstunde (Treasure Hour), wenn das Badge live ist: Die Truhen-Chancen verbessern sich.
4. Gib die Token im Piraten-Shop aus, bevor das Event endet.

## Schatzstunde

Ein begrenztes Zeitfenster, in dem das Schatzstunden-Badge live geht und die Chancen auf High-Tier-Truhen steigen. Prüfe das Live-Badge auf [fortyworth.com](https://fortyworth.com), bevor du in die Queue gehst.

## Kontosicherheit (lies das zuerst)

- Wir fragen nie nach deinem Epic-Games-Passwort. Es gibt keine „Konto-Verifizierung“, die eines verlangt.
- Die Anmeldung läuft nur über `accounts.epicgames.com` mit dem offiziellen „Sign in with Epic Games“-Flow (OAuth) — dein Passwort tippst du auf der Seite von Epic ein, die App erhält nur einen eingeschränkten Token.
- Wer nach deinem Passwort oder einem 2FA-Code fragt („Admins“, „Support“, „Verifikations-Bots“), macht Phishing. Melden und schließen.
- Aktiviere 2FA: epicgames.com → Konto → Passwort & Sicherheit → Zwei-Faktor-Authentifizierung.
