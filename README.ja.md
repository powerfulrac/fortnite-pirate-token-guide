## 海賊トークンとは？

「海賊トークン（Pirate Shop Access Token）」はコミュニティの呼び名で、Treasure Huntersミニシーズンのイベント通貨です。マッチ中に高ティアの埋もれた海賊チェストを回収して獲得し、海賊テーマのアイテムショップで使います。

## 最速の入手方法（TL;DR）

1. 埋もれた海賊チェストがスポーンする海岸エリアに着地。
2. 高ティアチェストを掘る — 1マッチで最も多くトークンが手に入ります。
3. トレジャーアワー（Treasure Hour）のバッジが有効な間にプレイ — チェストの出現確率が上昇します。
4. イベント終了前に海賊ショップでトークンを使い切る。

## トレジャーアワー

トレジャーアワーのバッジが有効になり、高ティアチェストの出現確率が上昇する限定時間帯です。マッチに参加する前に、[fortyworth.com](https://fortyworth.com)でライブバッジを確認しましょう。

## アカウントの安全対策（最初に読んでください）

- 私たちはあなたのEpic Gamesパスワードを尋ねることは一切ありません。パスワードを要求する「アカウント認証」も存在しません。
- サインインは`accounts.epicgames.com`上で、公式の「Epic Gamesでサインイン」（OAuth）フローを通じてのみ行われます。パスワードを入力するのはEpicのページであり、アプリが受け取るのは限定トークンだけです。
- パスワードや2FAコードを求めてくる相手（「管理者」「サポート」「認証ボット」など）はフィッシングです。報告して閉じてください。
- 2FAを有効にしましょう：epicgames.com → アカウント → パスワードとセキュリティ → 二段階認証。
