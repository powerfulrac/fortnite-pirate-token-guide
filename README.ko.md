## 해적 토큰이란?

해적 토큰(Pirate Shop Access Token)은 커뮤니티에서 부르는 이름으로, Treasure Hunters 미니 시즌의 이벤트 화폐입니다. 매치 중 고티어 묻힌 해적 상자를 회수해서 얻고, 해적 테마 아이템 상점에서 사용합니다.

## 가장 빠른 획득 방법 (TL;DR)

1. 묻힌 해적 상자가 스폰되는 해안 지역에 드롭합니다.
2. 고티어 상자를 파냅니다 — 매치당 가장 많은 토큰을 얻을 수 있습니다.
3. 트레저 아워(Treasure Hour) 배지가 켜져 있을 때 플레이합니다 — 상자 확률이 좋아집니다.
4. 이벤트가 끝나기 전에 해적 상점에서 토큰을 씁니다.

## 트레저 아워

트레저 아워 배지가 활성화되고 고티어 상자 확률이 좋아지는 한정 구간입니다. 큐를 잡기 전에 [fortyworth.com](https://fortyworth.com)에서 실시간 배지를 확인하세요.

## 계정 보안 (먼저 읽어 주세요)

- 저희는 Epic Games 비밀번호를 절대 요구하지 않습니다. 비밀번호가 필요한 "계정 인증" 같은 것은 존재하지 않습니다.
- 로그인은 `accounts.epicgames.com`에서 공식 "Epic Games로 로그인"(OAuth) 절차로만 이뤄집니다. 비밀번호는 Epic 페이지에서 직접 입력하고, 앱은 제한된 토큰만 받습니다.
- 비밀번호나 2FA 코드를 요구하는 사람("관리자", "고객 지원", "인증 봇")은 피싱입니다. 신고하고 창을 닫으세요.
- 2단계 인증(2FA)을 켜세요: epicgames.com → 계정 → 비밀번호 및 보안 → 2단계 인증.
