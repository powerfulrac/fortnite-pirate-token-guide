## 海盗代币是什么？

海盗代币（Pirate Shop Access Token）是玩家的习惯叫法，指 Treasure Hunters 迷你赛季的活动货币。在对局中收取高阶埋藏海盗宝箱即可获得，可在海盗主题商城中消费。

## 最快获取方法（TL;DR）

1. 跳伞到会刷新埋藏海盗宝箱的海岸区域。
2. 挖高阶宝箱——单局掉落的代币最多。
3. 在寻宝时刻（Treasure Hour）徽章生效时游玩——宝箱概率提升。
4. 活动结束前在海盗商城把代币花掉。

## 寻宝时刻

寻宝时刻徽章生效、高阶宝箱概率提升的限定时段。排队前先在 [fortyworth.com](https://fortyworth.com) 查看实时徽章。

## 账号安全（请先阅读）

- 我们绝不会询问你的 Epic Games 密码。不存在需要密码的“账号验证”。
- 登录只在 `accounts.epicgames.com` 上通过官方的“使用 Epic Games 登录”（OAuth）流程完成——密码只在 Epic 的页面输入，应用只会收到一个受限令牌。
- 任何索要密码或 2FA 验证码的人（“管理员”、“客服”、“验证机器人”）都是钓鱼诈骗。请举报并关闭页面。
- 开启两步验证（2FA）：epicgames.com → 账号 → 密码与安全 → 两步验证。
