# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository or its templates, **do not open a public
issue**. Use GitHub's **Security tab → Report a vulnerability** (private disclosure), or contact the
maintainer through the repository profile.

## Scope

- This repository contains **documentation, guides, and issue templates only** — there is no
  executable code, no build pipeline, and no server-side component here.
- The companion web tracker ([fortyworth.com](https://fortyworth.com)) is a separate service.
  Vulnerabilities in the site itself should be reported through the site's own contact channel.

## Account & credential safety

- This project never asks for your **Epic Games password** or any account credentials, and neither
  should any third-party site. Report anyone who does.
- Never share API keys or tokens (including GitHub `ghp_` tokens) in issues, comments, or
  screenshots.

## Data collection

This repository does not collect, store, or process personal data.
