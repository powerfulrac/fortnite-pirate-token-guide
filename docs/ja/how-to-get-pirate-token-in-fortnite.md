# Fortniteで海賊トークンを入手する方法（2026年版 ステップバイステップガイド）

> **手っ取り早い答え：** [FortyWorth ライブトラッカー](https://fortyworth.com)を開いて無料の**ロッカースキャン**を実行し、ロッカーの価値をチェックします。**トレジャーアワー（Treasure Hour）**が有効な時間帯にマッチへ参加し、**埋もれた海賊チェスト**が集中するルートを回って、**海賊トークン（Pirate Shop Access Token）**を受け取りましょう。トークンがあれば、対象のアイテムショップコスメを**14日間**アンロックできます。その期間中に受け取ったものは、ロッカーに永久に残ります。
>
> *ガイド最終更新：2026年11月。*

**海賊トークン（Pirate Shop Access Token）**は、**Fortnite: Treasure Hunters**ミニシーズンの報酬です。力任せに狙うなら、取り合いが最も激しいPOIに着地して、過酷な基本RNGと抽選勝負することになります。本ガイドで解説するのは、[Fortnite Pirate Token Finder](https://github.com/powerfulrac/fortnite-pirate-token-guide)リポジトリの中核にある、トラッカーを活用する速いルートです。流れは[FortyWorth ライブトラッカー](https://fortyworth.com)と同じものです。

## 必要なもの

- Fortniteがインストール済みの**Epic Gamesアカウント**。PC、PS5、Xbox Series X|S、Nintendo Switch、どのプラットフォームでも手順は同じです。
- トラッカーには**任意のWebブラウザ**でOK。PCやゲーム機に何かをインストールする必要はありませんし、トラッカーがEpic Gamesのパスワードやアカウント情報を求めることも一切ありません。

## ステップ1 — FortyWorth.comでロッカーをスキャンする

いつものブラウザで[fortyworth.com](https://fortyworth.com)を開き、**無料のロッカースキャン**を実行しましょう。スキャンは公開設定になっているロッカーを読み取り、スキン、エモート、バックアクセサリーなどインベントリ全体の価値を**V-BucksとUSD**で概算します。ログイン不要、Epicの認証情報も不要、スマホからでも使えます。

## ステップ2 — ロッカーの価値をチェックする

スキャンの直後に、概算の**ロッカー価値**が表示されます。これは、マッチに時間をかける前にスキャンが正常に完了したかを確認する方法でもあります。さらに詳しい内訳やシェアできる価値カードが欲しい場合は、[Fortniteロッカー価値・アカウント価値の調べ方](../locker-value.md)を参照してください。

## ステップ3 — トレジャーアワーのカウントダウンを見る

メインダッシュボードで**トレジャーアワー ステータスバッジ**とライブのカウントダウンタイマーを確認しましょう。**トレジャーアワー**は、サーバー側で日程が組まれた倍率ウィンドウで、**海賊トークンのドロップ率が急上昇**する時間帯です。トークンの入手スピードを左右する最大の要因です。全サーバー共通の固定スケジュールは公開されていないため、古いサードパーティの時刻表ではなく、ライブバッジを信頼しましょう。詳細：[トレジャーアワー スケジュール＆ライブタイマー](../treasure-hour-schedule.md)。

## ステップ4 — ウィンドウ中に高密度チェストルートを回す

バッジが点灯した瞬間にマッチへ参加し、**埋もれた海賊チェスト**と**レア・ブルーチェスト**が集中している3つのCrossbones Island周回ルートのいずれかを消化します。1マッチで回せる対象チェストが多いほど、ドロップ率ブースト中の抽選回数が増えます。ほとんどのプレイヤーに最適なのは**Shoreline Wreckage**（高ティアチェスト10〜14個、デュオ/スクワッド向け）です。詳細：[チェストルートガイド](../chest-routes.md)。

## ステップ5 — 海賊トークンを受け取り、アイテムショップを開く

**海賊トークン（Pirate Shop Access Token）**をEpicアカウントで受け取ったら、Fortniteの**アイテムショップ**を開き、対象のアウトフィット、エモート、バンドルを**14日以内に無料**でアンロックしましょう。2週間のウィンドウ中に受け取ったものは、ウィンドウが閉じた後も**ロッカーに永久に残ります**。

## トークンが反映されないとき

以下のチェックリストを順番に確認してください。

1. マッチ中にトレジャーアワーのバッジが実際に**有効**だったか確認します。受け取り時刻をダッシュボードのウィンドウ履歴と突き合わせましょう。
2. トラッカー上で**受け取りステップ**まで完了しているか、ゲーム内で**同じEpicアカウント**にログインしているか確認します。
3. Fortniteクライアントを再起動してアイテムショップを開き直します。トークンが有効な間、対象アイテムにはマークが付きます。
4. それでも出ない場合は、マッチ時刻とルートを添えてこのリポジトリでIssueを立ててください（Issueテンプレートを利用）。ルートデータとウィンドウ報告のクロスチェックに使われます。
