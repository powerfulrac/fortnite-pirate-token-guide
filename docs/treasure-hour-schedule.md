# Fortnite Treasure Hour Schedule & Live Timer (2026)

> **Treasure Hour** is the scheduled server-side window when **Pirate Shop Access Token** drop rates
> spike. If your goal is getting the token fast, everything else in this guide is secondary to
> queuing **inside** the window.
>
> *Guide updated: November 2026.*

## Why there is no fixed schedule on this page

Treasure Hour windows are **scheduled by the game's servers**, and the slots rotate. Any "fixed"
time list copied around the internet goes stale quickly — and a stale list costs you matches queued
at the wrong hour. That is why this repo links to a **live countdown** instead of printing hard times:

- The [FortyWorth Live Tracker](https://fortyworth.com) shows the **current window status badge** and
  a **countdown timer** for the next window.
- The dashboard's community feed logs **verified server resets** and recent token claims, so you can
  see when windows actually fired for other players.

## How to use the timer

1. Open [fortyworth.com](https://fortyworth.com) **before** you queue.
2. If the badge is **live** — queue immediately and run your densest route
   ([Shoreline Wreckage](chest-routes.md) is the default pick).
3. If the badge shows a **countdown** — warm up in a low-stakes mode, or prep your locker scan and
   claim flow, then queue when it flips.
4. Check the **community drop feed** to confirm other players are claiming tokens in the current
   window — it is the fastest sanity check that your region is boosted.

[Treasure Hour report issue](https://github.com/powerfulrac/fortnite-pirate-token-guide/issues/new?template=pirate-token-report.yml):

```text
Date (YYYY-MM-DD):        2026-11-__ 
Window start (UTC):       __:__
Window end (UTC):         __:__
Server / region:          
Route run:                Shoreline Wreckage / Coastal Cave Run / Lagoon Geyser Chain
High-tier chests opened:  
Pirate Token claimed?:    yes / no
Notes:                    
```

Paste the filled values (replace the underscores) into the issue body. Reports are cross-checked
against the dashboard feed before they influence the heatmap and schedule view.
