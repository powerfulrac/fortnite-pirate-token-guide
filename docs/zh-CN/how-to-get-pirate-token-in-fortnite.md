# 如何在 Fortnite 中获取海盗代币（2026 分步指南）

> **快速答案：** 打开 [FortyWorth 实时追踪器](https://fortyworth.com)，运行免费的**仓库扫描**，查看你的仓库价值；在**寻宝时刻（Treasure Hour）**生效期间进入对局，刷一条**埋藏的海盗宝箱**高密度路线，然后领取你的**海盗代币（Pirate Shop Access Token）**。令牌让你可以在 **14 天内**解锁商城中符合条件的装扮——在这段时间内领取的所有内容，都会永久留在你的仓库里。
>
> *攻略更新：2026 年 11 月。*

**海盗代币（Pirate Shop Access Token）**是 **Fortnite: Treasure Hunters** 迷你赛季的奖励。硬刷意味着你要降落在争夺最激烈的 POI，和残酷的基础 RNG 硬碰。本攻略讲的是 [Fortnite Pirate Token Finder](https://github.com/powerfulrac/fortnite-pirate-token-guide) 仓库所围绕的那条更快的、借助追踪器的路线——与 [FortyWorth 实时追踪器](https://fortyworth.com)使用的流程相同。

## 你需要准备什么

- 安装了 Fortnite 的 **Epic Games 账号**——PC、PS5、Xbox Series X|S 或 Nintendo Switch，流程完全一样。
- 追踪器用**任意网页浏览器**即可。PC 或主机上不会安装任何东西，追踪器也绝不会索要你的 Epic Games 密码或任何账号凭据。

## 第 1 步 — 在 FortyWorth.com 扫描仓库

在任意浏览器打开 [fortyworth.com](https://fortyworth.com)，运行**免费仓库扫描**。扫描会读取你公开可见的仓库，按 **V-Bucks（V 币）和美元**估算价值——皮肤、表情动作、背饰，整个库存一览无余。无需登录，无需 Epic 凭据，手机上也能用。

## 第 2 步 — 查看仓库价值

扫描结束后立刻能看到估算的**仓库价值**。这也能让你在投入对局时间之前确认扫描确实成功。想要更详细的明细和可分享的价值卡片？参见 [如何查看 Fortnite 仓库价值与账号价值](../locker-value.md)。

## 第 3 步 — 盯紧寻宝时刻倒计时

在主仪表板上查看**寻宝时刻状态徽章**和实时倒计时。**寻宝时刻**是服务器端排定的倍率时段，**海盗代币掉率会在此飙升**——这是决定拿币速度的最大因素。不存在对所有服务器都一直准确的固定公开时间表，所以请相信实时徽章，而不是过时的第三方时刻表。详情：[寻宝时刻时间表与实时计时器](../treasure-hour-schedule.md)。

## 第 4 步 — 在时段内刷一条高密度宝箱路线

徽章一亮就立刻排队进对局，跑三条 **Crossbones Island** 轮换路线之一——它们集中了**埋藏的海盗宝箱**和**稀有蓝宝箱**。每局可用的目标容器越多，掉率加成期间的抽奖次数就越多。对大多数玩家来说，最佳路线是 **Shoreline Wreckage**（10–14 个高阶宝箱，双人/小队）。完整解析：[宝箱路线指南](../chest-routes.md)。

## 第 5 步 — 领取海盗代币并打开商城

**海盗代币（Pirate Shop Access Token）**在 Epic 账号上领取之后，打开 Fortnite **商城**，在 **14 天内免费**解锁符合条件的服装、表情动作和捆绑包。两周时段内领取的一切都会**永久保留在你的仓库里**——即使时段结束也不会消失。

## 令牌没有到账怎么办

按顺序排查以下清单：

1. 确认你那局比赛中寻宝时刻徽章确实处于**生效**状态——把领取时间与仪表板的时段历史对照。
2. 确认你已在追踪器上完成**领取步骤**，并且游戏内登录的是**同一个 Epic 账号**。
3. 重启 Fortnite 客户端并重新打开商城——令牌生效期间，符合条件的物品会带有标记。
4. 还是没到账？带着你的对局时间和路线在本仓库开一个 issue（见 issue 模板），供路线数据和时段报告交叉核对。
